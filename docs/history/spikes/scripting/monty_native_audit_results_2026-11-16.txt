Fork at aac99ca9 (step budget phases 0-3), release build, Windows 10, max_memory 2 GB unless noted.
Each case runs in its own process; "steps" and "wall" cover only the operation (setup excluded).
Reference: a plain bytecode loop costs 4.3 ns per step. A hole is an operation whose ns/step is far above that.
Harness bugs (not Monty): case 32 (str.maketrans missing), 60 (del unsupported), 94 (io import is a host call),
80 (Decimal of 10^6 digits refused: 4300-digit coefficient limit), 7/8 (int<->str 4300-digit limit, as CPython).
Case 6 (pow(7, 3**100000, m)) did not finish in 90 s: sized wrongly by me, but it shows one operation can run for hours.
Case 69 (re.sub on 12 MB) did not finish in 90 s: see the re sub rows (100-102), quadratic or worse.
