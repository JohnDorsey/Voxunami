A second run of `seed_probe inversion`, after the source was formatted (the same results, only the timings differ): 7.1 ns each for the parent from the child, and 43.0 us for the seed from one property (still found at try 1,621 of 2048).

Notes. The GPU column is hashcat's published SHA-256 speed (22,138.4 MH/s, version 7.0.0) used as a stand-in for a hash, not a measurement of BLAKE3 on a GPU. Each section was run once: the one-off timings (39.2 us, 1.2 ms) are single runs; the search rate agrees across the three sizes (174, 168, 164 million a second). The probe's own random inputs come from a small xorshift driver; the first section checks terrain::mix against the published splitmix64 value so that the engine's function is the one under test.
